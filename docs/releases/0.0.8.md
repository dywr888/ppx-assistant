# 皮友助手 0.0.8

## 本次更新

- 新增"隐藏游戏入口"开关：隐藏首页右上角的小游戏入口。
- 新增"隐藏话题栏位""隐藏消息栏位"开关：隐藏底栏对应标签，"我的"等其余标签不受影响。
- 底栏隐藏兼容宿主的服务端标签配置：宿主按位置动态替换标签时同样保持隐藏，不破坏宿主自身的切换逻辑。
- 关闭开关即恢复原状；隐藏只作用于本机显示，不影响账号与服务端数据。

## 使用说明

开关位于"界面与个人资料"分类。修改开关后需强行停止皮皮虾再打开。适配皮皮虾 6.5.5、6.5.0、6.2.0。应用内检查更新读取 LSPosed 收录仓库的 Release。

包名 io.github.vs2pk0.piyou，内部版本号 20261011，可覆盖安装旧版模块；本次不是 LSPatch 集成包。

## 验证

真机（REDMI K90，皮皮虾 6.5.0，LSPosed API 102）：三个开关全开后顶栏只剩搜索图标、底栏为 [首页, +, 我的]，"我的"页可正常打开，模块 0 初始化失败；关闭开关恢复原状。宿主 6.5.0 与 6.5.5 的相关类名与签名一致（dex 逐一核对）。33 项单元测试与正式构建通过。
