# 皮友助手 0.0.9

## 本次更新

- 修复 LSPosed 开启"Xposed API 调用保护"后模块完全不生效的问题。该开关会把框架中的 Xposed API 类名随机化，模块此前按类名字符串查找 libxposed 接口，导致找不到类、所有功能都没有装上；现改为直接引用类型，开启或关闭该开关都能正常加载。
- 功能与适配范围与 0.0.8 相同。

## 使用说明

更新后强行停止皮皮虾再打开即可，无需重启手机。适配皮皮虾 6.5.5、6.5.0、6.2.0。应用内检查更新读取 LSPosed 收录仓库的 Release。

包名 io.github.vs2pk0.piyou，内部版本号 20261017，可覆盖安装旧版模块；本次不是 LSPatch 集成包。

## 验证

真机（REDMI K90，LSPosed IT 2.1.0-it (7779)，API 102，已开启"Xposed API 调用保护"）：修复前启动皮皮虾报 `ClassNotFoundException: io.github.libxposed.api.XposedInterface$Hooker`，模块未装上任何功能；修复后启动提示"加载成功; hooks=42"，模块 0 初始化失败，运行时 hook 回调正常触发。
