# 皮友助手 0.0.7

## 本次更新

- 适配皮皮虾 6.5.5：逐项核对宿主类与成员，Hook 全部加载成功；修复弹幕发送者查询在新版宿主中资料兜底入口失效的问题。
- 检查更新改用 LSPosed 官方模块仓库（Xposed-Modules-Repo）的 Release，更新弹窗与下载链接指向官方仓库页面。
- 新增"关闭个人信息保护指引"开关，隐藏启动时的个人信息保护指引弹窗。
- 新增"隐藏福利入口"开关，隐藏底栏中的福利中心入口。
- 抑制宿主因非官方包校验（结果码 11303）弹出的卸载提示弹窗。
- 设置在模块进程启动后才修改时，前台会提示需强行停止皮皮虾；加载失败会提示设置读取异常。

## 使用说明

适配版本列表为皮皮虾 6.5.5、6.5.0、6.2.0。覆盖安装后请在 LSPosed 中确认作用域仍勾选皮皮虾，并强行停止皮皮虾后重新打开。自动操作沿用既有处理，继续隐藏停用。

包名 io.github.vs2pk0.piyou，内部版本号 20261010，可覆盖安装旧版模块；本次不是 LSPatch 集成包。

## 验证

真机（小米 13 Ultra，Android 16，LSPosed API 102）对 6.5.5 宿主逐项核对 dex，唯一失效点已修复；冷启动主进程与 push 进程均加载成功，映射缓存 62 项全部解析，日志无初始化失败。30 项单元测试与正式构建通过。深流程（视频保存、红色评论等）本轮验证到 Hook 挂接层面，详见项目内 6.5.5 适配记录。
